# Tasks - Index

This is the main index for Agile Airframe Tasks. Tasks track broad implementation work packages under Epic milestones.

## Organization

- **Task-backlog.md**: Proposed Tasks not assigned to a Sprint.
- **Task-active.md**: Tasks assigned to a Sprint and in progress.
- **Task-unverified.md**: Implemented Tasks awaiting human verification.
- **Verified/**: Human-verified Tasks, one file per Task or batch.
