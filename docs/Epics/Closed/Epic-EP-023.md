# EP-023: AgileCockpit Plan Review and Approval

**Status:** Closed
**Owner:** Human / Airframe Planning
**Start Date:** TBD
**Target Close Date:** TBD
**Close Date:** 2026-07-07

**Goal:**
Let AgileCockpit present proposed implementation plans for human review, approval, deferral, or rejection before work begins.

**Rationale:**
Planning conversations currently happen outside the human-facing cockpit. Capturing proposed plans in AgileCockpit would make scope, expected changes, and approval state visible before implementation without conflating planning approval with final verification.

**Scope:**
- Define a plan record or presentation model for proposed implementation work.
- Show plan scope, file changes, commands, external effects, and verification criteria in AgileCockpit.
- Support explicit human approve, defer, and reject decisions.
- Record plan decisions in canonical state, audit events, or evidence records as appropriate.
- Preserve existing authority boundaries for human-only verification and closeout.

**Out of Scope:**
- Replacing existing human-only verification or closeout gates.
- Allowing agents to self-approve implementation plans.
- Remote workflow policy changes.
