**Observed Behavior:**
AgileCockpit applies workflow mutations to the checked-out branch and can write directly to a protected default branch.

**Expected Behavior:**
Mutations detect protected branches and dirty worktrees, route changes through an explicit review branch, preserve existing changes, and report the destination branch.

**Reproduction Steps:**
1. Open a workspace on main, perform a mutating operation such as Sprint close, and observe canonical and projected changes written directly to main.
