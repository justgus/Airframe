## I-0033: Empty narrative fields render as blank sections in Sprint and Epic detail views

**Observed Behavior:**
Sprint and Epic detail views print a field header with no value when the underlying narrative field is empty. SP-039 renders '**Goal:** ' with nothing after it and EP-025 renders '**Goal:**' followed by whitespace, which reads as a missing feature rather than missing content. Task detail omits the rationale line entirely when empty.

**Expected Behavior:**
Empty narrative fields render an explicit placeholder such as 'None recorded.', matching how Issue detail already handles empty observedBehavior, expectedBehavior, and reproductionSteps sections.

**Reproduction Steps:**
1. Open AgileCockpit. From the Dashboard status tiles select Sprints > Planning > SP-039, or Epics > Active > EP-025, or Tasks > Active > T-0190. Observe the Goal or rationale section in the detail pane.
