## I-0027: Add AICockpit commands for acceptance criteria, test suites, and Epic readiness

**Status:** Implemented - Verified
**GitHub Issue:** TBD
**Severity:** Medium
**Epic:** EP-024
**Sprint Assigned:** TBD
**Date Reported:** 2026-07-07
**Date Resolved:** 2026-07-07
**Date Verified:** 2026-07-07

**Observed Behavior:**
Agents must bypass AICockpit and edit canonical JSON directly to create Epic acceptance criteria, attach them to Epics, create canonical test suites, and fully describe newly created canonical Issues. AICockpit also lacks a read-only Epic readiness command that summarizes AC coverage and close blockers.

**Expected Behavior:**
AICockpit should provide first-class commands for canonical acceptance criteria, test suites, Epic coverage, and non-mutating Epic readiness checks so agents can manage review-blocking workflow data without direct JSON edits.

**Reproduction Steps:**
1. Inspect AICockpit help for acceptance-criteria commands.
2. Observe that no acceptance-criteria create, list, inspect, update, or link commands exist.
3. Attempt to define EP-024 acceptance criteria through AICockpit.
4. Observe that the available path requires direct canonical JSON creation and edits.
5. Inspect AICockpit help for test-suite commands.
6. Observe that test definition commands exist, but test-suite create, list, inspect, and update commands do not.
7. Create a canonical Issue through AICockpit.
8. Observe that only ID, title, and status can be supplied through the command.

**Affected Components:**
- AICockpit
- AirframeCore
- Markdown Projection
- Canonical State

**Notes:**
- Observed while preparing EP-024 for closure review. EP-024 had no acceptance criteria recorded, and AICockpit had no command to create or attach canonical acceptance criteria.
- AICockpit issue create can create the canonical Issue shell, but cannot populate issue detail fields such as observed behavior, expected behavior, reproduction steps, affected components, or notes.
- AICockpit tests create/update can manage test definitions, but there are no first-class commands for canonical test suites or coverage-driven linking between Epics, acceptance criteria, and tests.
- Generated Epic Markdown did not render the newly attached acceptance criteria after canonical export, even though canonical diagnostics passed and requirement matrices included the AC IDs.
- Acceptance Criteria: AICockpit can create, list, inspect, update, and link canonical acceptance criteria.
- Acceptance Criteria: AICockpit can attach acceptance criteria to Epics without direct JSON editing.
- Acceptance Criteria: AICockpit can create, list, inspect, and update canonical test suites.
- Acceptance Criteria: AICockpit can report Epic coverage, including ACs present, ACs linked to tests, uncovered ACs, and traceability gaps.
- Acceptance Criteria: AICockpit can preview Epic close readiness without performing human-only closure or verification actions.
- Acceptance Criteria: Markdown export renders Epic acceptance criteria consistently from canonical state.
- Acceptance Criteria: Tests cover the new commands, coverage diagnostics, and projection behavior.
