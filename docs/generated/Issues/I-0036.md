## I-0036: Sandboxed commands cannot resolve external GitHub API DNS

**Status:** Active
**GitHub Issue:** TBD

**Epic:** EP-025
**Sprint Assigned:** SP-043
**Date Reported:** TBD
**Date Resolved:** TBD

**Observed Behavior:**
Commands executed inside the workspace sandbox fail DNS resolution for api.github.com (curl error 6), while the same request succeeds when granted escalated execution.

**Expected Behavior:**
AICockpit and diagnostic commands should either reach configured external backends under their approved execution context or clearly disclose the sandbox-specific network restriction before reporting a backend failure.

**Reproduction Steps:**
1. Run curl -sS -I https://api.github.com inside the workspace sandbox; observe DNS resolution failure. Repeat with escalated execution; observe HTTP 200.

**Affected Components:**
- Execution sandbox, AICockpit GitHub integration
