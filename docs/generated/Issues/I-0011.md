## I-0011: Epic close does not archive Markdown Epic record

**Status:** Implemented - Verified
**GitHub Issue:** #149
**Severity:** High
**Epic:** EP-018
**Sprint Assigned:** SP-023
**Date Reported:** TBD
**Date Resolved:** 2026-06-25
**Date Verified:** 2026-06-25

**Observed Behavior:**
AgileCockpit closeActiveEpic transitions the canonical Epic status and clears the active Epic pointer, but it does not write a closed Epic Markdown record under docs/Epics/Closed/.

**Expected Behavior:**
When an authorized human closes an Epic, AgileCockpit should preserve the closed Epic as docs/Epics/Closed/Epic-<ID>.md and remove the closed Epic from the active Epic projection.

**Reproduction Steps:**
1. Open AgileCockpit with canonical Airframe state.
2. Close an eligible Epic.
3. Inspect docs/Epics/Closed/ and observe no Epic archive file was written by the close action.

**Affected Components:**
- AgileCockpit
- Documentation
- Canonical State

**Evidence:**
- TBD

**Notes:**
- Acceptance Criteria: 1. Closing an eligible Epic writes docs/Epics/Closed/Epic-<ID>.md. 2. The archived Epic preserves closeout details from canonical state. 3. The active Epic projection no longer contains the closed Epic. 4. Regression coverage proves the archive write occurs during Epic close.
- Resolution: AgileCockpit now writes closed Epic Markdown archives from canonical state after Epic close and refreshes Epic projections.
