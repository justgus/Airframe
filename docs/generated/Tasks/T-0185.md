**Rationale:**

**Acceptance Criteria:**
1. Canonical evidence records can be created, loaded, listed, and attached to supported work items.
2. Attachment updates reciprocal Evidence-to-Work-Item relationships atomically and idempotently.
3. Existing evidence records remain backward compatible.
