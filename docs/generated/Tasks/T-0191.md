**Rationale:**
The launch cache is the largest tracked artifact in the repository. Its fingerprint is a full path|kind|size|mtime line per file under .airframe/state, and its payload carries three sets of duplicated records. The fingerprint is only ever compared for equality, so a digest preserves behavior.

**Acceptance Criteria:**
1. launchFingerprint and traceabilityFingerprint emit a fixed-length digest instead of a concatenated per-file metadata listing.
2. Cache invalidation behavior is unchanged: an edit under .airframe/state still invalidates, and an unchanged tree still hits the cache.
3. canonicalSnapshot is removed or reduced to fields not already carried by canonicalState.
4. records and dashboardRecords no longer both appear in the payload.
5. agilecockpit-launch-cache.json for this repository drops below 800 KB, from 2,072,407 bytes.
6. AgileCockpit launches, renders the dashboard, and passes ac-launch-cockpit.sh --clear-cache followed by a cold rebuild.
