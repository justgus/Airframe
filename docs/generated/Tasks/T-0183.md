**Rationale:**
AgileCockpit writes workflow mutations to whatever branch is checked out, including protected or default branches, and can disturb pre-existing working-tree changes. This task detects branch and worktree state before writing, routes protected-branch mutations to a selected or newly created review branch, and identifies the destination branch in the UI.

Constraint: Never silently mutate a configured protected branch.

**Acceptance Criteria:**
1. Mutating operations detect current branch and working-tree state before writing.
2. Protected/default branches require explicit routing to a selected or newly created review branch.
3. Pre-existing tracked and untracked changes are preserved.
4. Confirmation and completion UI identify the destination branch.
5. Tests cover clean and dirty worktrees, protected branches, and branch-creation failure.

**Test Steps:**
- Unit, integration, and UI tests plus a branch-safety manual scenario.
