**Rationale:**
The active Epic and Sprint are stored in both the workspace configuration file and canonical project state, so the two can disagree and readers cannot tell which governs. This task removes the configuration pointers, makes every consumer resolve active context from canonical state, and migrates existing configuration without losing unrelated settings.

Constraint: Canonical project state remains the sole mutable active-context source.

**Acceptance Criteria:**
1. Workspace configuration no longer stores active Epic or Sprint pointers.
2. All consumers resolve active context from canonical project state.
3. Existing workspace configuration migrates without losing unrelated settings.
