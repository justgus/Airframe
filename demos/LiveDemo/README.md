# Airframe Live Demo Project-Local Installation

This directory is the project-local install target for Airframe live demo artifacts. It keeps demo products inside the repository and does not install into `/Applications`, `/usr/local/bin`, shell startup files, or package-manager locations.

## Layout

```text
demos/LiveDemo/
├── bin/aicockpit
├── Applications/AgileCockpit.app
├── DerivedData/
└── README.md
```

`bin/aicockpit`, `Applications/AgileCockpit.app`, and `DerivedData/` are generated by the install flow and ignored by git.

## Install

From the repository root:

```sh
scripts/install-live-demo.sh
```

The script builds `AICockpit` with SwiftPM, builds `AgileCockpit` with `xcodebuild`, and copies the resulting artifacts into `demos/LiveDemo/`.

By default the installed artifacts use:

```text
.airframe/airframe-workspace.json
```

That configuration should identify repository `justgus/Airframe` and backend `github-issues`.

## Verify

Run the SP-012 verification command:

```sh
scripts/verify-sp012.sh
```

The verification flow:

- installs project-local artifacts;
- checks `demos/LiveDemo/bin/aicockpit` is executable;
- checks `demos/LiveDemo/Applications/AgileCockpit.app` exists;
- runs configuration diagnostics through the installed `aicockpit`;
- runs a live `github-issues` project summary through the installed `aicockpit`;
- runs automated AgileCockpit tests without requiring a manual app launch.

## Manual Launch Later

Manual AICockpit and AgileCockpit demo runs are deferred until the live demo slices are complete. When manual launch is approved, use the project-local app path:

```sh
AIRFRAME_CONFIG_PATH=.airframe/airframe-workspace.json \
AIRFRAME_STORE_PATH=.airframe/airframe-local-backend.json \
open demos/LiveDemo/Applications/AgileCockpit.app
```
